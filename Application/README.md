# Cyber Security Essentials — Training Dashboard

iParhai-style training dashboard: course listing + module-wise course content.

Games are not built here. `Launch Game` is a placeholder until a game is assigned to a lesson in `src/data/trainings.js`.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173`

- `/` — Game-Based Training catalog
- `/course/:courseId/:lessonId` — Course Content
